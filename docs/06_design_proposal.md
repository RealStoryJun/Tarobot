# 🌌 타로봇 디자인 제안: 신비로운 미니멀리즘 (Mystic Minimalism)

기존의 답답했던 상단 바 디자인을 탈피하고, 타로의 신비로운 분위기를 극대화하기 위한 새로운 디자인 전략입니다.

## 1. 디자인 철학: "공간의 조화"
*   **배경과의 통합:** UI 요소가 배경 위에 '박혀' 있는 것이 아니라, 우주와 같은 배경 공간속에 자연스럽게 '떠 있는' 느낌을 줍니다.
*   **여백의 미:** 메인 타이틀인 "AI 타로 마스터"가 중앙에서 주인공이 될 수 있도록 상단 요소를 최소화합니다.

## 2. 세부 요소 전략 (톤 앤 매너)

### A. 고스트 버튼 (Ghost Buttons)
*   **로그인/회원가입:** 고체 색상의 버튼 대신, 테두리만 있는 투명한 버튼을 사용합니다.
*   **색상:** 메인 테마색인 크림색(`#f0e68c`)을 0.4~0.7 정도의 투명도로 사용합니다.
*   **효과:** 마우스를 올렸을 때만 불투명도가 100%가 되며 은은하게 빛나는 효과(Glow)를 주어 상호작용을 강조합니다.

### B. 타이포그래피 (Typography)
*   **세리프의 우아함:** 본문은 고딕체(`Gowun Dodum`)를 유지하되, 버튼이나 강조 텍스트는 얇고 우아한 느낌을 주도록 폰트 두께(`font-weight`)를 조절합니다.
*   **텍스트 그림자 생략:** 가독성을 위한 최소한의 그림자 외에는 인위적인 효과를 배제하여 깔끔함을 유지합니다.

### C. 상단 영역 (Header Area)
*   **투명성:** 상단 바의 경계선을 완전히 없애고 배경이 투명하게 비치도록 합니다.
*   **로고 생략:** 중앙 타이틀과 중복되는 상단 로고를 과감히 삭제하여 시야를 확보합니다.

## 3. 기대 효과
*   사용자가 사이트에 접속했을 때 거추장스러운 메뉴 바 없이 **오직 자신의 고민과 타로 카드**에만 집중할 수 있는 몰입도 높은 환경을 제공합니다.
*   현대적인 웹 디자인 트렌드인 'Glassmorphism'과 'Minimalism'이 결합되어 서비스의 신뢰도와 신비감을 동시에 높입니다.
